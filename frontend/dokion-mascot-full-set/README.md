# Dokion Mascot Full Set

Original mascot identity set prepared from the approved six-concept direction

## Primary identity
- Primary mascot: `01-core`
- Outline: `#30323D`
- Accent: `#D97958`
- Neutral fill: `#FFFDF8`

## Character roles
1. Core: default Dokion mascot and primary logo mark
2. Reviewer: code inspection and review
3. Terminal: CLI and developer-facing contexts
4. Guardian: policy, safety, and software hardening
5. Debugger: issue discovery and scanner findings
6. Focus: targeting, scope, and validation

## Included formats
- Editable SVG mascot characters
- Dark and light monochrome SVG variants
- Horizontal and stacked logo lockups
- Editable and outlined wordmarks
- PNG icons from 16 to 1024 px
- Multi-size `.ico` favicon
- SVG favicon
- Apple and Android app icons
- Web app manifest and browser configuration
- Social avatar and Open Graph card
- Color tokens in JSON and CSS

## Recommended usage
- Use the Core character as the default brand mark
- Use role characters inside documentation, product states, scanner results, onboarding, and release notes
- Do not add shadows, gradients, 3D effects, or additional facial detail
- Preserve the original stroke weight and clear space around each mascot
