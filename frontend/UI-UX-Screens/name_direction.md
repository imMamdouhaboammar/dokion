# Skillaude Name Direction

**Platform Name:** Skillaude  
**Tagline:** Build Skills That Think With You

## 1. Purpose

This document defines how the name **Skillaude** should be understood, positioned, and used across product, brand, interface, and communication contexts.

Use this document to keep naming decisions consistent.

## 2. Naming Intent

**Skillaude** is a coined product name built from two conceptual anchors:

- **Skill**: the core unit of value in the product
- **Claude-adjacent phonetics**: a deliberate tonal reference to calm, structured, builder-oriented AI workflows

The name should signal a serious workspace for creating, testing, validating, packaging, and managing AI skills.

It should not feel like a generic chatbot, a prompt toy, or a trend-driven AI app.

## 3. Product Reality Behind the Name

The naming direction should stay grounded in how the product actually works:

- Claude Code skills are structured through a `SKILL.md` file and related resources
- skills can be invoked directly or loaded when relevant
- the product is local-first in spirit and benefits from persistent browser storage patterns
- the platform is built for skill creation, inspection, testing, packaging, and reuse

Because of that, **Skillaude** should always feel like the name of a structured builder workspace, not a casual assistant.

## 4. What the Name Must Communicate

The name should consistently imply:

- structured AI capability building
- repeatability and reuse
- practical experimentation
- calm intelligence
- tool-grade seriousness
- composure and clarity
- a premium but restrained product experience

## 5. Brand Character

Skillaude should feel:

- intelligent
- composed
- precise
- useful
- mature
- technical, but not cold
- premium, but not luxurious
- modern, but not loud

It should not feel:

- playful for the sake of playfulness
- theatrical
- overhyped
- futuristic in a cliché way
- robotic
- noisy or aggressive

## 6. Strategic Role of the Name

Use **Skillaude** as the master product name.

Correct uses:

- product name
- platform name
- workspace name
- builder environment name

Incorrect uses:

- generic label for any skill
- feature label replacing functional feature names
- internal codename exposed in UX
- umbrella term for unrelated tools

## 7. Name Logic

The logic of the name is straightforward:

- **Skill** signals structure, capability, and repeatable use
- **aude** creates a subtle echo of the calm, thoughtful environment associated with Claude-oriented workflows

This gives the product a clear conceptual center: a place where AI skills are built, tested, refined, and packaged.

## 8. Positioning Statement

Recommended short positioning statement:

**Skillaude is a workspace for building, testing, and packaging AI skills.**

Recommended extended positioning statement:

**Skillaude is a local-first workspace for creating, validating, testing, importing, and exporting structured AI skills for Claude, ChatGPT, and other agent platforms.**

## 9. Descriptor Guidance

Approved descriptor options:

- AI skills workspace
- skill builder platform
- AI skill design and testing workspace
- local-first skills platform
- skill creation environment

Avoid these descriptor patterns:

- chatbot
- assistant clone
- prompt generator
- magic AI builder
- all-in-one AI universe
- no-code miracle platform

## 10. Official Name Format

Use the name exactly as:

**Skillaude**

Do not write:

- SKILLAUDE
- skillaude
- SkillAude
- Skill-Claude
- Skill Claude
- Skillaud
- Skillode

Use title case in product-facing and brand-facing contexts unless a specific UI pattern requires sentence case.

## 11. Tagline Rules

Primary tagline:

**Build Skills That Think With You**

Rules:

- keep exact capitalization
- do not casually rewrite it in core brand materials
- do not substitute “Think” with trend words
- do not add punctuation unless layout requires it

Approved lockup:

- Skillaude
- Build Skills That Think With You

## 12. First-Mention Rule

On first mention in a product page, deck, or document, use:

**Skillaude is a workspace for building, testing, and packaging AI skills.**

After first mention, use one of the following:

- Skillaude
- the platform
- the workspace

Do not repeatedly explain the wordplay.

## 13. Naming Hierarchy

Recommended hierarchy:

- **Master product name:** Skillaude
- **Tagline:** Build Skills That Think With You
- **Feature names:** descriptive and functional
- **Internal code names:** hidden from public-facing UX

Recommended feature naming examples:

- Skillaude Builder
- Skillaude Library
- Skillaude Test Workspace
- Skillaude Import
- Skillaude Export
- Skillaude Handoffs

Avoid feature names that compete with the master name or try to become sub-brands too early.

## 14. Visual and Verbal Pairing Rules

Because the name carries a Claude-adjacent echo, the surrounding design and copy must stay disciplined.

Do:

- keep the interface calm and restrained
- emphasize structure, workflow, testing, validation, and packaging
- build trust through clarity
- make the product feel original, not derivative

Do not:

- copy Claude language too literally
- imply official Anthropic affiliation
- present the product as an Anthropic property
- use surrounding copy that creates endorsement confusion

## 15. Browser Title and App Title Guidance

Preferred app title patterns:

- Skillaude
- Skillaude Workspace
- Skillaude Builder

Preferred browser title pattern:

- Skillaude | Build Skills That Think With You

Avoid long SEO-stacked titles.

## 16. Copy Rules Around the Name

Headlines and supporting copy around the name should be simple, exact, and controlled.

Good examples:

- Build and test AI skills in Skillaude
- Import a repo and turn it into a skill in Skillaude
- Continue your last draft in Skillaude

Weak examples:

- Meet Skillaude, the ultimate AI revolution
- Skillaude unlocks the future of limitless intelligence
- The most advanced next-gen platform for infinite AI creation

## 17. Legal and Brand-Safety Guidance

Skillaude is a strong working brand, but it is clearly inspired by the Claude naming environment.

Before public launch, review:

- trademark risk
- domain availability
- confusion risk in target markets
- visual and verbal distancing from official Anthropic properties

Use the name confidently, but do not position it in a way that implies ownership, endorsement, or official association.

## 18. One-Line Rule

When in doubt, follow this rule:

**Use Skillaude as the name of a calm, structured, builder-grade workspace for AI skills. Do not treat it like a generic chatbot brand or an official Anthropic product.**
