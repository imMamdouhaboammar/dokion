The script has three primary bottlenecks in the CSV parsing loop that cause significant memory pressure.

1. List Accumulation: Storing every line in a list (data) causes O(n) memory growth. For a 500MB file, this exceeds typical heap limits when objects are instantiated.

2. String Splitting: The line.split(',') creates multiple string objects per line, increasing garbage collection overhead.

3. IO Buffering: Standard file reading without explicit buffering sizes is suboptimal for high-throughput data.
